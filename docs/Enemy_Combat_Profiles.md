Critical-hit chances are now used for enemies as well as companions. Damage is per landed hit; specials retain their authored attack names and control effects.

## Scenery review

All mission references now use full illustrated scenes from img/pictures. Woodland routes use QuestWoodland_v8; shrines, crypts and undead locations use QuestCrypt_v8; coastal routes use QuestCoast_v8; mountain and fire routes use QuestMountain_v8; underground routes use BattleCavern_v1. Floor-only battlebacks, abstract colors and fantasy-number aliases were removed from mission references. Existing scenic assets were reused; no new illustrations were generated. Old saves that lock a battleback floor use the current scenic quest background.

Review contact sheets: tests/background-review-contact.webp and tests/background-scenery-review.webp. Actual game screenshots: tests/visuals/rebalance-816-mission.webp and rebalance-1280-mission.webp.
